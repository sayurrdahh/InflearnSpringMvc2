속성 설정

속성 추가

- th:attrappend = 속성 값의 뒤에 값을 추가한다 (th:attrappend="class='large'" => class=textlarge)
- th:attrprepend = 속성 값의 앞에 값을 추가한다 (th:attrprepend="class='large'" => class=largetext)
- th:classappend = class 속성에 자연스럽게 추가한다 (th:classappend="large" => class=text large)

checked 처리

- 타임리프의 th:checked는 값이 false인 경우 checked 속성 자체를 제거한다.
- checked o
- checked x
- checked=false
